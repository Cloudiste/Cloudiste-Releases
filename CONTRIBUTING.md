# Participer à la bêta de Cloudiste

Les retours recherchés concernent notamment :

- les smartphones, tablettes, consoles Android, télévisions et écrans externes ;
- les manettes et dispositions de boutons inhabituelles ;
- l’installation et les mises à jour avec Obtainium ;
- le lancement des applications et services web ;
- la lisibilité, les textes et les traductions ;
- les fonds, GIF et vidéos ;
- les crashs, blocages et comportements reproductibles.

## Faire un retour utile

Indique :

1. la version de Cloudiste ;
2. le modèle de l’appareil et sa version Android ;
3. les étapes exactes permettant de reproduire le problème ;
4. le résultat attendu et le résultat observé ;
5. une capture si elle ne contient aucune donnée personnelle ;
6. le rapport produit par **Réglages > Diagnostic et retour bêta**, uniquement si tu acceptes de le partager.

Avant de signaler un problème, vérifie la [dernière Release](https://github.com/Cloudiste/Cloudiste-Releases/releases/latest) et consulte le [guide de dépannage](docs/SAUVEGARDE-ET-DIAGNOSTIC.md).
