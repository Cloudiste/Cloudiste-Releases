# Sécurité

## APK officiels

Les versions officielles de Cloudiste sont uniquement publiées dans les Releases de ce dépôt. Vérifiez l’empreinte SHA-256 fournie avec chaque APK avant l’installation en cas de doute.

## Signaler un problème

Ne publiez jamais de mot de passe, de cookie de connexion, de sauvegarde personnelle ou de journal contenant des identifiants. Utilisez le rapport de diagnostic anonymisé produit par Cloudiste lorsque celui-ci est suffisant.

## Clé de signature

La clé privée de signature de Cloudiste n’est pas conservée dans ce dépôt. L’empreinte publique du certificat est documentée dans le README afin de permettre la vérification des versions.
