# Cloudiste 0.62.3 — Nouveaux logos animés

Cette version remplace les animations optionnelles des services par treize nouveaux logos animés, chacun avec son propre mouvement et son propre rythme.

## Nouveautés

- nouvelles animations pour GeForce NOW, Boosteroid, Xbox Cloud Gaming, PlayStation Plus Premium, Amazon Luna, Shadow PC, Moonlight, Steam Link, Parsec, Antstream, Blacknut, OpenNOW et Better xCloud ;
- fichiers WebP transparents de 212 × 212 pour conserver un cadrage homogène ;
- répétition continue des animations tant qu’elles restent visibles ;
- rendu cohérent dans les modes détaillé, compact et plein écran ;
- remplacement automatique de l’ancien visuel lorsqu’un logo animé était déjà sélectionné ;
- présentation des nouveautés mise à jour en français, anglais et espagnol.

Les logos animés restent une option de personnalisation. Les logos fixes demeurent le choix par défaut.

## Vérifications

- version Android `0.62.3`, code `92` ;
- APK et AAB release signés avec le certificat historique de Cloudiste ;
- compilation release, R8 et Lint vital réussis ;
- 401 contrôles instrumentés validés sur Medium Tablet API 35 ;
- sélection, répétition et cadrage vérifiés visuellement dans les trois modes d’affichage.
