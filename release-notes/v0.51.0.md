# Cloudiste 0.51.0 bêta

Cette version finalise le **partage des packs de thèmes**.

## Changements

- Nom, créateur et description personnalisables pour chaque pack.
- Partage direct du fichier `.cloudiste-theme` avec le menu Android.
- Aperçu enrichi avant import : informations, version source, nombre de visuels et premier média.
- Signalement des services inconnus ou incompatibles sans bloquer les éléments reconnus.
- Détection des archives et médias manquants ou invalides.
- Bouton pour restaurer le thème précédent après un import.
- Lecture des packs 0.50 maintenue.
- Interface tactile et manette, traduite en français, anglais et espagnol.

## Mise à jour

Vous pouvez installer directement `Cloudiste-0.51.0-release.apk` ou laisser Obtainium détecter cette Release. Le centre de mises à jour de Cloudiste ouvre la page de téléchargement dans le navigateur externe.
