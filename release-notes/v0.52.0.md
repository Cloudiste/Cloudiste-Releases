# Cloudiste 0.52.0 bêta

Cette mise à jour renforce la stabilité, la navigation à la manette et la conformité avant les prochains tests publics.

## Changements

- Le centre de mises à jour respecte désormais le canal d’installation : Google Play pour une installation Play, GitHub pour une installation directe ou Obtainium.
- Les versions GitHub invalides sont ignorées et les vérifications restent mises en cache pendant six heures.
- La navigation à la manette reconnaît les axes HAT et adapte la zone morte au contrôleur détecté.
- La luminosité personnalisée des fonds vidéo est correctement appliquée.
- Le dock utilise les couleurs du thème Sombre, OLED ou Clair.
- Un indicateur s’affiche pendant le chargement initial.
- Cloudiste récupère proprement des réglages endommagés et en informe l’utilisateur.
- Le premier focus des pages secondaires vise directement une action utile.
- Android connaît maintenant les trois langues de l’application et les règles de sauvegarde.
- L’icône adaptative prend en charge les icônes thématiques monochromes.

- Application : `fr.cloudiste.launcher`
