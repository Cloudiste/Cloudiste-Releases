# Cloudiste 0.48.0 bêta

Cette version ajoute un centre de mises à jour intégré à Cloudiste.

## Changements

- Nouvelle rubrique **Centre de mises à jour** dans les Réglages.
- Affichage de la version installée et de la dernière version publiée.
- Notes de release récupérées depuis le dépôt GitHub officiel.
- Indication du canal utilisé : **GitHub / Obtainium** ou **Google Play**.
- Bouton d’actualisation manuelle et cache de six heures.
- Conservation des dernières informations en cas d’échec réseau.
- Ouverture de la release GitHub dans le navigateur externe.
- Point discret sur le pictogramme Réglages lorsqu’une nouvelle version est disponible.
- Interface et libellés disponibles en français, anglais et espagnol.

Cloudiste ne télécharge ni n’installe les mises à jour automatiquement. Obtainium ou Google Play continuent de gérer l’installation selon le canal utilisé.

## Mise à jour

Vous pouvez installer directement `Cloudiste-0.48.0-release.apk` ou laisser Obtainium détecter cette Release.

## Vérification

- Application : `fr.cloudiste.launcher`
- Version : `0.48.0`
- Code de version : `67`
- APK signé : oui
