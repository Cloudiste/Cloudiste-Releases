# Cloudiste 0.46.3 bêta

Cette version corrige le cadrage des images personnalisées des dossiers **Émulateurs** et **Jeux Android**.

## Changements

- Les images personnalisées des dossiers sont affichées entièrement par défaut dans leur tuile.
- Le cadrage, la position et l’assombrissement de la tuile sont désormais indépendants de ceux du fond plein écran.
- Une même image peut toujours être utilisée pour les deux emplacements.
- Les anciens dossiers reçoivent automatiquement le cadrage corrigé.
- Ces réglages distincts sont aussi disponibles pour les services cloud et les applications ajoutées.

## Mise à jour

Vous pouvez installer directement `Cloudiste-0.46.3-release.apk` ou laisser Obtainium détecter cette Release.
