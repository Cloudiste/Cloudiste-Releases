# Cloudiste 0.51.1 bêta

Cette mise à jour améliore l’utilisation de l’accueil et l’alignement des réglages.

## Changements

- Le bandeau et le logo Cloudiste se réduisent progressivement lorsque la liste des services défile vers le bas.
- Le bouton Quitter accompagne cette réduction et reste facilement utilisable.
- Le bandeau reprend sa taille normale en remontant la liste.
- Le texte **Retour aux services** est maintenant centré dans son bouton.
- L’écran des nouveautés respecte la langue sélectionnée dans Cloudiste.

## Vérification

- Application : `fr.cloudiste.launcher`
- Version : `0.51.1`
- Code de version : `71`
- APK signé : oui
- Contrôles automatisés : `360` réussis

Vous pouvez installer directement `Cloudiste-0.51.1-release.apk` ou laisser Obtainium détecter cette Release.
