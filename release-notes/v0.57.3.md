# Cloudiste 0.57.3 bêta — Retour à la base 0.56.1

Cette release retire les fonctions de gestion avancée de l’accueil introduites en 0.57.0. Cloudiste revient à l’accueil simple et aux fonctions de la 0.56.1 : tuiles déplaçables, dossiers, personnalisation, thèmes, sons et musique d’ambiance.

La sélection multiple avec X, les actions groupées, les tris automatiques, les tailles globales de tuiles, le verrouillage et les pages Cloud/Android/Émulation/Multimédia ont été retirés. Les autres réglages et contenus restent conservés lors de la mise à jour.

**Si la 0.57 est déjà installée**, installez l’APK de cette release par-dessus : le code de version Android `82` permet la mise à jour directe avec le même certificat. Obtainium peut également proposer cette release. La 0.56.1 historique reste accessible dans les anciennes releases.
