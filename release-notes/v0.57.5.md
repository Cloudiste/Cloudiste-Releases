# Cloudiste 0.57.5 bêta — Gestes de l’accueil

Le logo et le dock répondent désormais à deux gestes distincts sur l’accueil :

- **Swipe vers le haut** : le logo Cloudiste se réduit et remonte. Sa réduction est plus marquée sur smartphone. Le dock garde sa taille normale.
- **Swipe vers le bas** : le logo reprend sa taille initiale et le dock se compacte, sur téléphone comme sur tablette.

Les boutons du dock gardent une zone d’appui d’au moins 48 dp. Les gestes ne modifient ni l’ordre des tuiles ni les personnalisations enregistrées. Cette version conserve la base d’accueil rétablie en 0.57.3.

Téléchargez l’**APK** pour installer Cloudiste ou recevoir les mises à jour avec Obtainium. L’**AAB** est destiné à Google Play Console. Les fichiers `.sha256` permettent de vérifier les téléchargements.

## Vérification

- Application : `fr.cloudiste.launcher`
- Version : `0.57.5`, code Android : `84`
- APK et AAB signés avec le certificat Cloudiste historique
- Compilation Android et Lint réussis
- Les deux directions de swipe et le rendu du logo et du dock vérifiés sur émulateur Android en paysage
