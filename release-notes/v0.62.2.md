# Cloudiste 0.62.2 bêta — Recherche de jeux et navigation simplifiée

Cette publication réunit **toutes les évolutions réalisées depuis la dernière version GitHub, Cloudiste 0.58.0**.

## Trouver où jouer à un jeu

- nouvelle loupe **Rechercher un jeu** au centre du Dock ;
- disponibilité sur GeForce NOW, Xbox Cloud Gaming, Boosteroid et PlayStation Plus Premium ;
- recherche effectuée localement après un téléchargement quotidien unique du catalogue ;
- consultation hors connexion grâce au dernier catalogue valide ;
- jaquettes verticales chargées à la demande et mises en cache ;
- Xbox distingue **Game Pass** et **Si possédé** ;
- les boutiques GeForce NOW sont affichées lorsqu’elles sont fournies par la source ;
- Steam, Epic Games Store, GOG, Ubisoft, EA, Battle.net et Xbox sont directement sélectionnables pour ouvrir la boutique ;
- services et boutiques s’ouvrent dans leur application ou dans le navigateur externe ;
- date de mise à jour et attribution Cloud Dosage avec accès direct à leur blog.

## Une navigation plus cohérente

- résultats et fiches de jeux entièrement pilotables à la croix et aux sticks ;
- défilement automatique pour garder le focus visible ;
- sons, halo, animations et contraste identiques au reste de Cloudiste ;
- couleurs harmonisées dans les thèmes Sombre, OLED et Clair ;
- texte d’aide plus lisible ;
- lorsque Cloudiste est le launcher Android actif, Quitter est masqué et B ne ferme plus l’accueil.

## Dock et commandes contextuelles

- six raccourcis fixes : **Réglages, Applications, Dossiers, Recherche de jeux, Découvrir et Réglages Android** ;
- les applications épinglées restent affichées après ces six icônes ;
- le nom du raccourci sélectionné apparaît sous le Dock ;
- l’aide manette affiche jusqu’à trois commandes utiles selon le contexte ;
- la légende disparaît lors d’une interaction tactile et revient avec la manette.

## Réglages plus lisibles

- six sections : **Accueil, Apparence, Écran et accessibilité, Manette, Système, Aide et informations** ;
- navigation complète à la croix, aux sticks, avec A et B ;
- LB et RB servent de raccourcis supplémentaires entre les sections ;
- le bouton **@Cloudgamingfrance** ouvre maintenant directement la chaîne YouTube ;
- les références à Cloud Dosage sont cliquables.

## Installation

Télécharge l’**APK** pour installer Cloudiste ou recevoir la mise à jour avec Obtainium. L’**AAB** est destiné à Google Play Console. Les fichiers `.sha256` permettent de vérifier les téléchargements.

## Vérification

- application : `fr.cloudiste.launcher` ;
- version : `0.62.2`, code Android : `91` ;
- APK et AAB signés avec le certificat Cloudiste historique ;
- 401 contrôles Android réussis sur Medium Tablet API 35 ;
- compilation release, R8 et Android Lint réussis ;
- lien YouTube vérifié vers `https://www.youtube.com/@cloudgamingfrance`.
