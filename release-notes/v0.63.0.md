# Cloudiste 0.63.0 — Dossiers façon launcher

Cette version refond les dossiers **Émulateurs** et **Jeux Android** pour afficher en priorité leur contenu et simplifier leur utilisation au doigt comme à la manette.

## Contenu du dossier

- grille adaptative de quatre, cinq ou six colonnes selon la largeur de l’écran ;
- grandes icônes centrées et nom de l’application sur une ligne ;
- aucun nom de package affiché ;
- console indiquée pour les émulateurs reconnus ;
- première application focalisée à l’ouverture ;
- commandes d’administration déplacées dans l’en-tête ;
- menu contextuel pour retirer ou déplacer une application et ouvrir ses informations Android ;
- états dédiés pour un dossier vide et une application désinstallée.

## Gestion du dossier

- nom libre avec suggestions ;
- applications choisies regroupées en tête ;
- recherche instantanée ;
- filtres **Émulateurs détectés**, **Jeux** et **Toutes les applications** ;
- option **Récemment utilisés en premier** ;
- confirmation avant d’abandonner les modifications ;
- suppression isolée dans une zone sensible.

## Manette

- `A` ouvre ou sélectionne ;
- `Y` affiche les options ;
- `X` ouvre la gestion du dossier ;
- `Start` personnalise ou enregistre ;
- `LB` et `RB` changent de section ;
- `B` revient en arrière.

## Vérifications

- version Android `0.63.0`, code `93` ;
- APK et AAB release signés avec le certificat historique de Cloudiste ;
- compilation release, R8, Lint vital et Lint debug réussis ;
- 420 contrôles instrumentés validés sur Medium Tablet API 35 ;
- textes synchronisés en français, anglais et espagnol.

## Installation

Téléchargez `Cloudiste-0.63.0-release.apk` ci-dessous. Les utilisateurs d’Obtainium recevront automatiquement cette version depuis le dépôt officiel.
