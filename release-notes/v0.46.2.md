# Cloudiste 0.46.2 bêta

Cette version apporte deux corrections visuelles ciblées.

## Changements

- Le mot-symbole Cloudiste dispose maintenant d’une marge de sécurité pour préserver tout le haut du **C**.
- Le logo utilise un affichage ajusté à son cadre sur tous les formats d’écran.
- Le texte du bouton **Retour** est centré dans le panneau de personnalisation ouvert par appui long.

## Mise à jour

Vous pouvez installer directement `Cloudiste-0.46.2-release.apk` ou laisser Obtainium détecter cette Release.

## Vérification

- Application : `fr.cloudiste.launcher`
- Version : `0.46.2`
- Code de version : `64`
- APK signé : oui
