# Cloudiste 0.53.0 bêta

Cloudiste peut de nouveau être choisi comme launcher Android, avec un démarrage renforcé et une procédure entièrement réversible.

## Changements

- Nouvelle rubrique **Réglages › Launcher Android**.
- Sélection par la confirmation officielle du rôle HOME d’Android.
- État du launcher affiché directement dans Cloudiste.
- Bouton permettant de tester immédiatement le bouton Accueil.
- Accès permanent aux réglages Android pour revenir au launcher constructeur.
- Lors d’un lancement système HOME, Cloudiste ouvre directement l’accueil sans assistant ni écran de nouveautés.
- Une tâche unique évite d’empiler plusieurs écrans Cloudiste lorsque le bouton Accueil est pressé plusieurs fois.

## Vérification

- Application : `fr.cloudiste.launcher`
- Version : `0.53.0`
- Code de version : `73`
- APK signé : oui, APK Signature Scheme v3
- Contrôles automatisés : `370` réussis
- Deux redémarrages consécutifs de l’APK signé : rôle HOME conservé et accueil Cloudiste affiché
- Validation sur la tablette cible : réussie

La fonction launcher reste facultative. Une installation ou une mise à jour ne remplace jamais automatiquement l’accueil Android.
