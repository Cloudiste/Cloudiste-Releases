# Guide utilisateur

## Premier démarrage

L’assistant propose successivement :

1. la langue ;
2. le thème Sombre, OLED ou Clair ;
3. un profil adapté à l’écran ;
4. les services détectés sur l’appareil ;
5. le mode d’affichage de l’accueil ;
6. la création facultative des dossiers Jeux Android et Émulateurs ;
7. un aperçu avant validation.

L’assistant peut ensuite être relancé depuis **Réglages > Assistant de démarrage**.

## Les trois affichages de l’accueil

- **Tuiles détaillées** : logo, nom, état et informations de lancement.
- **Tuiles compactes** : fond et logo dans un rectangle réduit.
- **Plein écran** : un service à la fois, avec son fond personnalisé.

Le bouton d’affichage placé en bas à droite ou la touche **Select** passe d’un mode au suivant. En plein écran, touche les flèches latérales, glisse horizontalement ou utilise LB et RB.

## Ajouter une application

Ouvre **Applications** depuis le dock. Un appui long au doigt ou la touche **Y** sur une application ouvre les actions permettant de :

- l’ajouter au dock ;
- l’ajouter comme service sur l’accueil ;
- retirer son raccourci du dock lorsqu’il existe déjà.

La suppression d’un raccourci ne désinstalle jamais l’application Android.

## Créer des dossiers

La rubrique **Dossiers** permet de créer un dossier Jeux Android ou Émulateurs, puis d’y sélectionner les applications voulues. Un appui long ou **Y** sur le dossier ouvre sa personnalisation et sa composition. Supprimer un dossier ne désinstalle pas son contenu.

## Personnaliser une tuile

Maintiens une tuile au doigt ou appuie sur **Y**. Le menu latéral propose, selon l’élément :

- les images et vidéos ;
- les éléments affichés ;
- le cadrage et la luminosité ;
- les applications d’un dossier ;
- la suppression d’un service ajouté manuellement.

Les médias acceptés comprennent les images, les GIF animés et les vidéos compatibles. Les animations de logo propres aux services sont facultatives et désactivées par défaut.

## Apparence

Dans **Réglages > Apparence**, tu peux choisir le thème, le fond général, la langue et le **Clean mode**. Le Clean mode masque les noms, états et notices de commandes sur l’accueil sans modifier les actions disponibles.

Le fond général peut rester identique pour tous les services. Le mode fond selon le service change l’arrière-plan avec la sélection. Les médias personnels restent stockés localement et sont inclus dans les sauvegardes.

## Écran et accessibilité

Les tailles Compacte, Normale et Grande adaptent les commandes et les tuiles. Les marges de sécurité TV éloignent les éléments interactifs des bords lorsqu’un écran externe est détecté.
