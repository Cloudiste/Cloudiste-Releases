# Sauvegarde, diagnostic et dépannage

## Sauvegarder la configuration

Ouvre **Réglages > Sauvegarde et récupération > Exporter une sauvegarde**. Le fichier `.cloudiste` peut contenir :

- les services et leur ordre ;
- les dossiers et leur contenu ;
- les applications placées dans le dock ;
- les thèmes et modes d’affichage ;
- les images, GIF et fonds personnalisés.

Les applications Android elles-mêmes ne sont pas copiées. Conserve le fichier dans un emplacement fiable avant une réinstallation ou un changement d’appareil.

## Restaurer

Choisis **Importer une sauvegarde**, puis sélectionne ton fichier `.cloudiste`. La configuration importée remplace la configuration actuelle. Une archive inconnue, incomplète ou trop volumineuse est refusée avant application.

## Diagnostic réseau

Dans **Réglages > Diagnostic et retour bêta > Diagnostic réseau** :

- le test rapide mesure la disponibilité, la latence, la gigue et les requêtes perdues ;
- le test complet ajoute les débits descendant et montant et demande une confirmation avant de consommer davantage de données ;
- le résultat indique le type de connexion et une appréciation adaptée au cloud gaming.

Le diagnostic ne transmet pas le nom du réseau Wi-Fi, l’adresse IP, les comptes ou les identifiants de connexion.

## Rapport bêta

Le rapport partageable peut inclure la version de Cloudiste, le modèle d’appareil, Android, WebView, les manettes détectées, l’état des services, le launcher sélectionné et les dernières erreurs techniques disponibles. Cloudiste demande explicitement si le rapport doit accompagner un signalement.

Relis toujours son contenu avant de le partager. N’ajoute jamais de mot de passe, cookie, adresse personnelle ou capture contenant des identifiants.

## Problèmes fréquents

### La mise à jour est refusée

Vérifie que tu as téléchargé l’APK depuis ce dépôt officiel. Une application portant le même identifiant mais signée avec un autre certificat ne peut pas la remplacer.

### Un fond vidéo reste noir

Essaie une vidéo plus courte ou moins lourde. Cloudiste prévoit un visuel de secours si Android ne parvient pas à reprendre le lecteur.

### Une application nouvellement installée n’apparaît pas

Ouvre **Applications** et utilise **Actualiser**. La liste mise en cache est affichée rapidement pendant qu’Android recherche les changements.

### Une manette produit de mauvaises commandes

Utilise **Tester ma manette**, relève son nom et partage le rapport de diagnostic avec une description précise du bouton concerné.
