# Commandes tactiles et manette

Toute fonction principale de Cloudiste est prévue pour fonctionner au doigt et à la manette.

| Action | Manette | Tactile |
| --- | --- | --- |
| Déplacer la sélection | Croix ou stick | Faire défiler ou toucher |
| Ouvrir ou valider | A | Toucher |
| Revenir | B | Bouton Retour |
| Personnaliser une tuile | Y | Appui long |
| Changer d’affichage | Select | Bouton en bas à droite |
| Parcourir le plein écran | LB et RB | Flèches ou glissement horizontal |
| Déplacer une tuile | Maintien selon l’écran | Maintenir puis glisser |

Un contour indique l’élément actuellement sélectionné avec la manette. Le focus suit aussi le dernier élément touché.

## Tester une manette

Ouvre **Réglages > Tester ma manette**. La page affiche en direct :

- A, B, X et Y ;
- Start et Select ;
- LB, RB, LT et RT ;
- L3 et R3 ;
- la croix directionnelle ;
- les deux sticks analogiques.

Dans cette page, un appui bref sur B est affiché comme entrée. Maintiens B pendant environ une seconde pour revenir aux réglages.

La disposition exacte des boutons peut varier selon le constructeur de la manette. Le test permet de voir les événements réellement transmis par Android.
