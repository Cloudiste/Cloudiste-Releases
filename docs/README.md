# Documentation de Cloudiste

Cloudiste rassemble les services de cloud gaming, les applications Android et les émulateurs dans une interface conçue pour le tactile et la manette.

## Commencer

1. [Installer Cloudiste et recevoir les mises à jour](INSTALLATION.md)
2. [Configurer et utiliser l’accueil](GUIDE-UTILISATEUR.md)
3. [Consulter les commandes tactiles et manette](COMMANDES.md)
4. [Sauvegarder ou diagnostiquer un problème](SAUVEGARDE-ET-DIAGNOSTIC.md)

## Principales fonctions

- trois affichages : tuiles détaillées, tuiles compactes et plein écran ;
- lancement d’applications Android et ouverture des services web dans le navigateur externe ;
- dossiers pour les jeux Android et les émulateurs ;
- fonds personnalisés avec images, GIF et vidéos ;
- thèmes Sombre, OLED et Clair ;
- français, anglais et espagnol ;
- navigation complète au doigt et à la manette ;
- diagnostic de la manette et de la connexion réseau ;
- sauvegarde et restauration des personnalisations ;
- réglages d’affichage pour smartphone, tablette, télévision et écran externe.
