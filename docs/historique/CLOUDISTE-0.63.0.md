# Cloudiste 0.63.0 — Dossiers façon launcher

Cette version refond les dossiers **Émulateurs** et **Jeux Android** pour afficher en priorité leur contenu et faciliter leur utilisation au doigt comme à la manette.

## Contenu du dossier

- grille adaptative de quatre, cinq ou six colonnes selon la largeur de l’écran ;
- grandes icônes centrées, nom de l’application sur une ligne et suppression des noms de package ;
- indication facultative de la console pour les émulateurs reconnus ;
- première application focalisée à l’ouverture et focus conservé au retour d’une application ;
- commandes d’administration déplacées dans l’en-tête ;
- menu contextuel pour retirer ou déplacer une application et ouvrir ses informations Android ;
- état spécifique pour un dossier vide ou une application désinstallée ;
- panneau assombri à 70 % au-dessus du fond personnalisé.

## Gestion du dossier

- nom libre avec suggestions localisées ;
- applications choisies regroupées en tête ;
- recherche instantanée ;
- filtres **Émulateurs détectés**, **Jeux** et **Toutes les applications** ;
- option **Récemment utilisés en premier** enregistrée avec le dossier ;
- actions **Annuler** et **Enregistrer** fixes en bas de l’écran ;
- confirmation avant de quitter avec des changements non enregistrés ;
- suppression déplacée dans une zone sensible séparée.

## Manette

- `A` ouvre ou sélectionne ;
- `Y` affiche les options d’une application ;
- `X` ouvre la gestion du dossier ;
- `Start` personnalise depuis le contenu et enregistre depuis le gestionnaire ;
- `LB` et `RB` passent entre les sections du gestionnaire ;
- `B` revient en arrière.

Tous les nouveaux textes sont disponibles en français, anglais et espagnol.
