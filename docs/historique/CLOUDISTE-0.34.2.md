# Cloudiste 0.34.2 — Fonds par défaut des dossiers

Les dossiers disposent maintenant d’une identité visuelle dès leur création.

Aucun dossier n’est créé ou affiché lors d’une installation neuve. Les fonds sont embarqués silencieusement et apparaissent uniquement lorsqu’un utilisateur crée volontairement un dossier depuis le dock. Une mise à jour conserve les dossiers déjà créés.

## Jeux Android

Le fond utilise un univers de jeu futuriste bleu nuit, cyan et vert. Les éléments inspirés d’une console portable restent sur les côtés afin de conserver une zone centrale calme et lisible.

## Émulateurs

Le fond représente une bibliothèque rétro en pixel art, avec des archives numériques et un portail lumineux. La palette et la luminosité restent cohérentes avec l’interface moderne de Cloudiste.

Les deux illustrations sont embarquées dans l’application en JPEG 1280 × 720. Elles servent automatiquement :

- d’image de la tuile ;
- de fond dans l’affichage plein écran ;
- d’aperçu dans le panneau de personnalisation.

Une image choisie par l’utilisateur remplace le visuel par défaut. Retirer cette image rétablit automatiquement le fond fourni avec Cloudiste.
