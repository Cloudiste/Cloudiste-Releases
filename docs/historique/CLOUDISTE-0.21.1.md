# Cloudiste 0.21.1 — Correctif du dock

Cette version corrective résout le crash rencontré depuis les boutons de réglages du dock.

## Correction

- Le panneau **Réglages** utilise désormais la même liste d’actions pour l’affichage et pour la navigation au focus.
- Xbox Cloud Gaming et Amazon Luna, qui fonctionnent uniquement dans le navigateur, ne créent plus de faux choix entre application et Web.
- Si Android refuse exceptionnellement d’ouvrir ses réglages système, Cloudiste reste affichée et signale que l’ouverture est indisponible.

## Contrôle sur appareil

1. Depuis l’accueil, touche **Réglages** : le panneau doit s’afficher sans fermeture de Cloudiste.
2. Reviens à l’accueil, puis touche **Réglages Android** : l’écran Android doit s’ouvrir.
3. Utilise le bouton Retour d’Android : Cloudiste doit réapparaître avec tes préférences conservées.
