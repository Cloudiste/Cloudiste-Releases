# Cloudiste 0.46.2 — Correctifs d’alignement

Cette version apporte deux corrections visuelles ciblées.

## Changements

- Le mot-symbole Cloudiste a été recadré sur son contenu avec une marge transparente de sécurité.
- L’en-tête utilise désormais `ContentScale.Fit` : le haut du C reste visible sur tous les formats d’écran.
- Le texte du bouton **Retour** est centré horizontalement dans le panneau de personnalisation ouvert par appui long.

## Test conseillé

1. Affiche le logo Cloudiste complet sur l’accueil et vérifie les quatre côtés du C.
2. Ouvre la personnalisation d’un service ou d’un dossier par appui long.
3. Vérifie que **Retour** est centré comme dans les autres menus.
4. Contrôle le résultat sur téléphone et tablette.
