# Cloudiste 0.62.1 — Dock à six icônes

Le dock fixe contient de nouveau six accès : Réglages, Applications, Dossiers, Recherche de jeux, Découvrir et Réglages Android. Les applications épinglées restent ajoutées après ces six icônes et le bouton de mode d’affichage reste séparé à droite.

La navigation à la croix et aux sticks reste disponible sur tous les écrans. Dans les Réglages, LB et RB sont uniquement des raccourcis supplémentaires pour changer de section : haut, bas, gauche, droite, A et B conservent leur fonctionnement complet.

Le raccourci YouTube ne revient pas parmi les actions fixes afin de conserver un dock à six icônes.
