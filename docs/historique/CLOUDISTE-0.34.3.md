# Cloudiste 0.34.3 — Accueil adapté aux smartphones

L’accueil mesure désormais la hauteur réellement disponible en paysage. Sous 520 dp, il passe automatiquement à une présentation compacte conçue pour les smartphones ; aucune option n’est nécessaire.

## Présentation compacte

- Les quatre services initiaux tiennent sur une seule ligne à partir de 720 dp de largeur.
- Les cartes mesurent 150 dp de haut. Le nom et l’état sont superposés sur un dégradé au bas du visuel.
- Le logo Cloudiste, le bouton Quitter, le dock et les marges verticales sont réduits.
- Les boutons principaux conservent une zone tactile de 48 dp.
- L’aide détaillée de la manette est masquée sur les écrans peu hauts afin de laisser la priorité aux services.
- Le mode plein écran utilise lui aussi une carte moins haute et un logo de service plus compact.

Sur tablette, la présentation détaillée existante reste active : grandes tuiles, description, mode de lancement et aide manette.

## À vérifier sur le smartphone

1. Installe l’APK 0.34.3 par-dessus la version actuelle.
2. Ouvre Cloudiste en paysage : les quatre services initiaux doivent être visibles sur une ligne.
3. Vérifie que le logo, le dock et les deux boutons latéraux ne se chevauchent pas.
4. Fais défiler verticalement si tu as ajouté assez de services pour créer plusieurs lignes.
5. Maintiens une carte puis déplace-la ; un glissement immédiat doit toujours faire défiler la liste.
6. Passe au mode plein écran et vérifie le parcours au doigt, à la croix, avec LB et RB.

Les préférences, les services personnels, les dossiers et les images restent conservés lors de la mise à jour.
