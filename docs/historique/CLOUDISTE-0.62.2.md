# Cloudiste 0.62.2 — Recherche de jeux et navigation simplifiée

Cette version publique réunit toutes les évolutions réalisées depuis Cloudiste 0.58.0.

## Disponibilité des jeux

- une loupe dédiée est placée au centre du Dock ;
- recherche locale sur GeForce NOW, Xbox Cloud Gaming, Boosteroid et PlayStation Plus Premium ;
- téléchargement du catalogue au maximum toutes les 24 heures, avec cache hors connexion ;
- jaquettes verticales chargées à la demande puis conservées dans le cache Android ;
- distinction Xbox entre **Game Pass** et **Si possédé** ;
- affichage des boutiques GeForce NOW fournies par le catalogue ;
- Steam, Epic Games Store, GOG, Ubisoft, EA, Battle.net et Xbox sont directement sélectionnables ;
- ouverture des boutiques et services dans leur application ou le navigateur externe ;
- date des données et attribution Cloud Dosage affichées avec un lien vers leur blog.

## Interface et manette

- recherche de jeux entièrement pilotable à la croix et aux sticks ;
- défilement automatique pour garder le résultat ou l’action sélectionnée visible ;
- focus, sons, halo et animations cohérents avec l’accueil ;
- palettes Sombre, OLED et Clair harmonisées, sans violet Material résiduel ;
- Quitter est masqué lorsque Cloudiste est le launcher Android actif ;
- aide manette réduite à trois commandes contextuelles maximum.

## Dock et Réglages

- six raccourcis fixes : Réglages, Applications, Dossiers, Recherche de jeux, Découvrir et Réglages Android ;
- les applications épinglées restent placées après ces six raccourcis ;
- le nom de l’élément sélectionné apparaît sous le Dock ;
- Réglages est organisé en six sections : Accueil, Apparence, Écran et accessibilité, Manette, Système, Aide et informations ;
- la croix, les sticks, A et B restent disponibles partout ;
- LB et RB changent rapidement de section dans les Réglages ;
- les références à Cloud Dosage ouvrent leur blog ;
- le bouton **@Cloudgamingfrance** ouvre directement la chaîne YouTube.

## Vérification

- version Android : `0.62.2`, code `91` ;
- APK et AAB signés avec le certificat Cloudiste historique ;
- compilation debug, tests Android, APK release, AAB release et Lint vital réussis ;
- 401 contrôles instrumentés réussis sur Medium Tablet API 35 ;
- ouverture de `https://www.youtube.com/@cloudgamingfrance` confirmée dans l’application YouTube.
