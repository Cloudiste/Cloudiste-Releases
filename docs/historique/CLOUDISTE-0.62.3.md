# Cloudiste 0.62.3 — Nouveaux logos animés

Cette version remplace les treize logos animés optionnels de Cloudiste par les nouvelles animations WebP transparentes fournies pour :

- GeForce NOW ;
- Boosteroid ;
- Xbox Cloud Gaming ;
- PlayStation Plus Premium ;
- Amazon Luna ;
- Shadow PC ;
- Moonlight ;
- Steam Link ;
- Parsec ;
- Antstream ;
- Blacknut ;
- OpenNOW ;
- Better xCloud.

Les animations conservent un canevas carré de 212 × 212 afin de garder la même taille et le même centrage dans les trois modes d’affichage. Elles restent facultatives : l’image fixe demeure le choix par défaut et une animation déjà sélectionnée est automatiquement remplacée par sa nouvelle version.

Cloudiste force désormais les animations embarquées à se répéter tant qu’elles sont visibles, même lorsque le fichier WebP ne demande qu’une seule lecture.
