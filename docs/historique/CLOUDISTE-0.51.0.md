# Cloudiste 0.51.0 — Packs de thèmes finalisés

Cette version rend les packs de thèmes plus simples à identifier, prévisualiser, partager et restaurer.

## Création et partage

- nom personnalisé du pack ;
- nom du créateur et description facultatifs ;
- export dans un fichier `.cloudiste-theme` ;
- partage direct vers les applications proposées par Android ;
- compatibilité maintenue avec les packs créés par Cloudiste 0.50.

## Aperçu et compatibilité

Avant l’import, Cloudiste affiche les informations du pack, sa version d’origine, le nombre de visuels et un aperçu du premier média disponible. Les services inconnus sont signalés puis ignorés sans bloquer les autres éléments compatibles. Une archive incomplète, invalide ou contenant un média dangereux reste refusée.

## Restauration

Après l’application d’un pack, l’action **Restaurer le thème précédent** remet l’apparence antérieure. Elle reste disponible jusqu’à la fermeture de la page des packs.

## Confidentialité

Les packs continuent d’exclure les applications, comptes, dossiers, dock, langue et réglages de lancement. Le partage Android utilise un accès temporaire limité au fichier créé.

## Vérification

- 359 contrôles automatisés réussis, dont 13 consacrés aux packs de thèmes ;
- validation sur émulateurs téléphone et tablette en orientation paysage ;
- menu de partage Android testé avec le fichier joint ;
- APK et AAB Release signés.
