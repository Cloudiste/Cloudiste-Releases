# Cloudiste 0.61.0 — Dock et commandes contextuelles

Cette étape simplifie la navigation de l’accueil sans modifier les services ni les applications épinglées.

## Dock

- six raccourcis fixes : Réglages, Applications, Dossiers, Rechercher un jeu, Découvrir et Réglages Android ;
- les applications ajoutées manuellement restent affichées après ces raccourcis ;
- le nom de l’élément focalisé apparaît sous le Dock ;
- le changement de mode d’affichage reste disponible avec Select et avec le bouton tactile à droite ;
- le thème reste accessible dans Réglages > Apparence.

## Aide manette

- la longue phrase d’aide est remplacée par trois commandes contextuelles maximum ;
- les commandes changent selon une tuile, le mode plein écran ou une application du Dock ;
- la légende disparaît lors d’une interaction tactile et revient à la première commande manette.
