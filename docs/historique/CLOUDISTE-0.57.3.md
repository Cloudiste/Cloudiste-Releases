# Cloudiste 0.57.3 — Retour à l’accueil de la 0.56.1

À la suite des retours sur la gestion avancée de l’accueil, cette version reprend le fonctionnement de la 0.56.1. Les fonctions ajoutées en 0.57 ont été retirées : sélection multiple, déplacement groupé, duplication visuelle, tri automatique, tailles globales, verrouillage et pages d’accueil facultatives. Le raccourci X de sélection multiple a également été retiré.

Les tuiles retrouvent leur ordre manuel et leur déplacement habituel. Les services, dossiers, personnalisations, thèmes, sons, musique d’ambiance, sauvegardes et autres fonctions de la 0.56.1 restent disponibles. Les nouveaux réglages éventuellement enregistrés en 0.57 sont ignorés ; les autres préférences sont conservées pendant la mise à jour.

Le numéro `0.57.3` et le code Android `82` permettent d’installer cette restauration au-dessus des versions 0.57 déjà installées. La release historique 0.56.1 reste disponible, mais son code Android `78` ne permet pas une mise à jour directe depuis la 0.57.
