# Cloudiste 0.34.4 — Correction du logo sur smartphone

Cette version corrige le mot-symbole Cloudiste tronqué dans la présentation compacte.

Sur les écrans peu hauts, le logo utilise désormais son rapport d’origine et est affiché entièrement dans une capsule légèrement ajustée. Aucun bord de l’image n’est recadré. La grille compacte, les quatre cartes par ligne et les dimensions tactiles ajoutées en 0.34.3 restent inchangées.

Installe l’APK par-dessus la version précédente, ouvre l’accueil en paysage et vérifie que le « C », la vague, toutes les lettres et le point bleu sont visibles.
