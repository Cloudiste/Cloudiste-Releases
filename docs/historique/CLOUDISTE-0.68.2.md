# Cloudiste 0.68.2 — Boutiques Boosteroid

- **Disponibilité des jeux** : les boutiques compatibles s'affichent désormais aussi pour Boosteroid (Steam, Epic Games Store, Xbox…), avec des liens cliquables, comme pour GeForce NOW.
- **Notes par service** : chaque service affiche une note explicative mise à jour depuis le serveur, par exemple « il faut posséder le jeu sur la boutique indiquée ». En anglais et en espagnol, l'application affiche ses propres textes traduits.
