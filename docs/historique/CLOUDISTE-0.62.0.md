# Cloudiste 0.62.0 — Réglages simplifiés

Les réglages passent de onze rubriques à six sections lisibles :

1. Accueil ;
2. Apparence ;
3. Écran et accessibilité ;
4. Manette ;
5. Système ;
6. Aide et informations.

La section Système réunit le launcher Android, les mises à jour, le catalogue et les sauvegardes. Aide et informations réunit l’assistant, les diagnostics, les contacts, la confidentialité et les crédits.

Les réglages s’ouvrent sur Accueil. LB et RB passent directement d’une section à l’autre et placent le focus sur sa première action. Le message « Réglages enregistrés » n’occupe plus l’écran en permanence.

Les références à Cloud Dosage ouvrent désormais explicitement leur blog dans le navigateur externe, y compris lorsque le catalogue n’a pas encore été téléchargé.
